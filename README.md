# Lasting Logo Design: Claude Skill

**Brand name → brand truth → brand nouns → logo directions → copy-ready AI prompts.**

A Claude skill for designing logos that last. Give it a brand name (and what you know about the brand) and it returns:

- a **brand truth** statement and a **name analysis**
- **30–50 brand nouns**, marked ownable ★ or cliché ○
- **idea pairings** (two ideas fused into one form)
- **4–6 logo directions** across logo types, with a recommended pick
- **concept-sheet and single-mark prompts** for Figma AI, ChatGPT, Midjourney, Ideogram or Firefly, plus iteration prompts
- an **avoid list**, then critique, stress tests, vector refinement and brand-system guidance

Inspired by the publicly described approach of **Allan Peters' _Logos That Last_** (Rockport, 2023): build on brand truth over trends, explore before narrowing, stress-test early, reduce to the threshold, and extend the mark into a system. All text here is original. Read the book for the full method and case studies.

## Install
**Claude Code / Agent SDK**
```bash
git clone https://github.com/krutikkkkkkkkk/lasting-logo-design ~/.claude/skills/lasting-logo-design
```
**Claude.ai / desktop app:** download the repo as a ZIP → *Settings → Capabilities → Skills → Upload*.

## Try it
> "Logo prompts for **Kiln & Kettle**, a small-batch tea café in Pune. Cosy, crafted, unpretentious."
> "Brand nouns and 5 logo directions for **Northbeam**, a B2B analytics startup."
> "Take direction 2 further: critique, stress tests and a refinement plan."

## Notes
- AI images are **concepts, not final logos**. Rebuild the chosen mark in vector.
- Always run a trademark search before launch. This skill is not legal advice.
